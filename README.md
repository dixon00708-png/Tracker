# Ultra + Lift Tracker

A dashboard for logging ultra-training runs and weightlifting sessions, with mileage, pace and lift-progress charts and automatic "add weight" suggestions.

## Run it on your own computer
```
pip install -r requirements.txt
streamlit run tracker_app.py
```
Then open http://localhost:8501. Data saves to `tracker_data.json` in this folder.

## Online version
Hosted on Streamlit Community Cloud. Saved data there can reset when the app restarts, so use **Settings → Download backup** now and then, and **Restore** if your entries disappear.
